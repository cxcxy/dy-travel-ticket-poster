# 旅行票根视觉规范

## 画布与几何

| 项目 | 规格 |
| --- | --- |
| 画布 | `1170 × 1560`，严格 `3:4` |
| 票根位置 | 水平与垂直居中 |
| 票根尺寸 | 约 `1058 × 425` |
| 票根占画布 | 宽约 `90.4%`，高约 `27.2%` |
| 负空间 | 约 `75%` |
| 左侧照片 | 票根宽度约 `74.7%`，目标比例约 `1.86:1` |
| 右侧信息联 | 票根宽度约 `25.3%` |
| 外边距 | 左右约 `4.8%` |

票根使用小圆角和克制的右下软阴影。照片与信息联之间使用短矩形竖向虚线。信息联最右侧垂直中点设置一个向内的半圆缺口。不要添加外边框。

## 信息层级

阅读顺序固定为：照片 → 大写标题 → 日期 → 编号 → 8 位序列码 → 装饰条形码。

```text
OLD
TOWN

2026 - 08

NO.19427
E5R8K3M2
||||||||||||
```

- 使用超粗几何无衬线体，左对齐。
- 标题通常分成两行；优先在词间换行，单个长词按视觉平衡拆分，不机械按固定字符数切割。
- 日期和编号使用同一家族粗体，字号低于标题。
- 条形码只是装饰，不声称可以扫描或编码真实数据。

## 自适应配色

1. 从照片提取 2 至 3 个代表色。
2. 背景使用主色的低饱和、中明度版本，维持大面积安静负空间。
3. 信息联使用同色系深浅色，或照片中清晰但不突兀的次主色。
4. 文字根据对比度选择暖白或深色；不要为了统一强行使用白字。
5. 保持照片自然，不叠加重滤镜、霓虹、复杂渐变或明显胶片特效。

常见映射：植物 → 灰绿与树皮棕；砖墙 → 陶土与砂岩；海景 → 青蓝；夕阳 → 焦橙；沙漠 → 沙米与旧红；精品店 → 香槟与灰粉。

## 内容边界

- 手机状态栏、通知、播放器、按钮和进度条属于截图伪影，全部排除。
- 不伪造城市、品牌、拍摄日期、人物身份、商品、招牌或可扫描票码。
- 不改变人物五官、发型、眼镜、服装、姿势和手部动作。
- 不增加或删除动物、车辆、建筑、产品和重要道具。
