# 旅行票根视觉规范

## 画布与排版选择

排版与背景仍可独立覆盖。`landscape` 和 `portrait` 都支持照片派生背景、用户指定色、统一色系和图集 12 风格；但用户没有指定风格时，`landscape` 默认照片主色纸纹，`portrait` 默认采用本次参考图的灰橄榄绿织物背景、暖象牙票纸和近黑油墨。

### `landscape` 原有横向票根

| 项目 | 规格 |
| --- | --- |
| 画布 | `1170 × 1560`，严格 `3:4` |
| 票根主体坐标 | 名义 `x=55, y=501`；阴影不计入主体边界 |
| 票根主体尺寸 | `1057 × 507px`，比例约 `2.08:1` |
| 票根占画布 | 宽 `90.4%`，高 `32.5%` |
| 负空间 | 约 `67.5%` |
| 左侧照片 | `774 × 507px`，票根宽度 `73.2%`，目标比例约 `1.53:1` |
| 右侧信息联 | `283 × 507px`，票根宽度 `26.8%` |
| 外边距 | 左 `55px`、右 `58px`；这是参考图缩放后的锁定值，不强行改成数学等宽 |
| 光学居中 | 票根主体中心比画布几何中心上移约 `26px`；下方软阴影补足视觉重心 |

这些参数来自已确认的参考布局、确定性版式脚本和通过验收的成品。生成目标使用精确值；目视验收容差为：左边距 `51–59px`、右边距 `54–62px`、两侧差值 `0–7px`，票根主体顶部 `489–513px`、高度 `495–519px`。超过容差必须重做，不能用“约居中”放行。

票根外轮廓使用小圆角。照片与信息联之间在画布 `x≈829px` 只能出现一条竖向虚线：宽 `7px`，短矩形段高 `14px`、间隔 `12px`，第一段从票根顶部开始，所有线段必须是直角矩形，虚线顶部不得圆角、不得留出圆角式空隙。信息联最右侧垂直中点设置一个向内的半圆缺口。不要添加外边框。

阴影使用两层：近距离接触阴影约偏移 `(3, 5)`、模糊 `8px`、低不透明度；大范围环境阴影约偏移 `(2, 12)`、模糊 `26px`、更低不透明度。阴影应在照片和信息联整张票根周围连续，尤其加强下缘的落地感；上缘保持克制。禁止阴影断裂、只出现在信息联、变成描边、发光、脏色块或第二张卡片。

### `portrait` 竖版收藏票根

| 项目 | 规格 |
| --- | --- |
| 画布 | `1170 × 1560`，严格 `3:4` |
| 票根主体 | `x=305, y=190, width=560, height=1180px` |
| 圆角照片区 | 票根内 `x=44, y=80, width=472, height=748px`，目标比例约 `0.63:1` |
| 横向撕票线 | 票根内 `y=884px`，`4px` 高、`22px` 方角短段、`14px` 间隔 |
| 信息区 | 撕票线下方；首行左侧编号、右侧标题，中部大条形码，底行日期与 8 位码 |
| 外轮廓 | `34px` 圆角；上下重复小齿口；上下居中大缺口；撕票线左右各一个半圆缺口 |

照片保持原始像素等比例竖向裁切，并只在照片窗的圆角处遮罩；不得把整张横图压扁填入。条形码为 `88px` 高，所有竖条顶部和底部各自齐平。标题优先单行右对齐，过长时才使用两行；标题仍使用粗体，日期、编号和 8 位码仍使用细窄等宽正文字体。上下齿口与撕票线属于排版几何，不得随背景风格改变。

## `landscape` 信息层级

阅读顺序固定为：照片 → 大写标题 → 日期 → 编号 → 8 位序列码 → 装饰条形码。

```text
OLD
TOWN

2026 - 08

NO.19427
E5R8K3M2
||||||||||||
```

- 使用超粗几何无衬线体，左对齐。
- 标题通常分成两行；优先在词间换行，单个长词按视觉平衡拆分，不机械按固定字符数切割。
- 日期和编号使用同一家族粗体，字号低于标题。
- 条形码只是装饰，不声称可以扫描或编码真实数据。

## 两种排版的默认背景

### `landscape`：照片主色 + 细腻哑光纸纹

完整执行 [palette-system.md](palette-system.md) 的来源取色、候选审美筛选和对比度检查；下列规则进一步锁定本 Skill 当前默认的克制柔和背景表现：

1. 从当前照片提取 2 至 3 个代表色；忽略极小面积高光、纯黑阴影、UI 和水印颜色。
2. 选择照片中有足够面积的环境主色作为画布色，保留其色相身份。默认把其 HSL 饱和度缩放至原色约 `72%`，限制在 `16–56%`；明度限制在 `46–68%`，使其克制柔和而非灰化或荧光化。
3. 用户没有指定材质、风格 ID 或背景氛围时，画布必须呈现为边到边的照片主色，并叠加细腻、低对比的哑光纸纹。推荐亮度变化约 `±2`，上限不超过 `±4`；远看保持干净整块主色，近看才有纸面触感。
4. 默认纸纹只允许细小纸面齿感与短纤维式微差，不得形成明显纸纤维、石材纹路、颗粒团块或可识别图案。禁止渐变、暗角、方向性光斑、窗影、树影、聚光、投影色块、上下不同色和大面积明暗变化。
5. 信息联使用照片中的深色或较鲜明次主色，与画布形成清楚层级，但不使用无来源的品牌色。优先保持同一色相家族或照片中真实出现的互补色。
6. 小号日期、编号和序列码与信息联的对比度至少达到 `4.5:1`；大标题至少 `3:1`。优先使用暖白 `#F4F0E5`，对比不足时加深信息联或改用深色文字。
7. 本段只适用于 `landscape`，以及用户明确要求 `portrait` 改用照片主色时。
8. 使用 `scripts/build_subtle_texture_background.py` 生成默认背景，固定种子保证同一输入与配置可复现。用户明确要求“纯色 / 无纹理”时才回退为完全纯色；旧版完全纯色仍可兼容读取，但不作为新任务默认。
9. 保持照片自然，不叠加重滤镜、霓虹、复杂渐变或明显胶片特效。

常见映射：植物 → 灰绿与树皮棕；砖墙 → 陶土与砂岩；海景 → 青蓝；夕阳 → 焦橙；沙漠 → 沙米与旧红；精品店 → 香槟与灰粉。

### `portrait`：参考图灰橄榄绿织物

用户选择 `portrait` 且没有指定背景时，锁定以下外部画布身份：

- 基准色为从参考图空白区测得的灰橄榄绿 `#92946E`；纹理与轻微光照会使实际像素围绕该色变化，不要求整张纯色。
- 票根纸面首选参考图暖象牙色 `#E8DECF`，不得再默认使用照片派生的深棕、墨绿或其他重色；备选旧纸暖米为 `#E2D6C4`，复古羊皮为 `#D9CAB5`。
- 标题、编号、日期、8 位码和条码统一使用参考图近黑油墨 `#1B1811`。首选票纸与文字对比约 `13.3:1`，票纸与外部画布 `Delta OK` 约 `0.25`。
- 材质为细密横纵交织的布面/亚麻壁布。实测主纱距约 `4–5px`，横纵纱线都有高光、暗槽与柔和肩部，间距、粗细和局部明暗只能轻微不规则；远看保持一块安静的绿，近看才能辨认纱线体积。禁止完全固定 `4px × 5px`、每条线等亮的电子屏幕网格，也禁止做成纸纹、草地、粗麻袋、随机噪点或油画画布。
- 光照从左上向右下柔和衰减，横向衰减强于纵向：参考图安全背景区左上约比色彩锚点亮 `18–20` 级、右下约暗 `16–18` 级。不得使用明显聚光、暗角、窗影或分块式渐变。
- 纹理强度以参考图安全背景区为准：去除大尺度光照后的局部亮度起伏约 `9–12`，相邻像素横向差约 `6–8`、纵向差约 `8–11`。明显低于该范围会像平面网格，明显高于该范围会像粗麻布并抢主体。
- 织纹只存在于外部画布；票根纸面保持干净暖白，照片保持自然，文字和条码保持近黑。
- 使用 `build_subtle_texture_background.py --layout portrait` 的 `auto` 路由确定性生成，固定种子保证可复现。
- 用户明确指定照片主色时，背景传 `--background-treatment photo-matte`，配色推荐器传 `--palette-treatment photo-derived`；用户指定纯色、统一色系或 12 风格时，显式选择覆盖本默认值。

## 图集锁定的 12 风格系统（显式启用）

用户指定 `style_id`、材质、氛围或“给我多套背景方案”时，外部画布从当前排版默认背景切换到图集风格模式。默认数据源为 [gallery-12-background-styles.json](gallery-12-background-styles.json)，必须通过 `scripts/background_style_system.py` 解析，不能凭印象手写参数。通用 20 风格基线继续保留在 [background-styles.json](background-styles.json)，仅在用户明确要求旧风格时通过 `--registry` 切换。

每个默认风格都包含：图集顺序、源文件名、源文件 SHA-256、实测背景中值色、视觉签名、材质、基础/辅助/高光色、纹理、推荐光线、推荐阴影、纵深、颗粒、氛围、主体关系、强度范围、适用场景、禁止项和 Prompt 片段。12 个风格与光线、阴影、强度、色温和主体保护参数解耦，可在保留风格身份的前提下组合。

图集只作为背景系统依据：提取材质、光型、明暗衰减和票根悬浮关系；不要复制其中的咖啡照片、人物、文字、编号、条形码或偶发生成瑕疵。实测色只作为身份锚点，不要求每个像素固定为同一色值。

### 组合规则

- 默认 `strength=balanced`、`subject_preservation=strict`。强度预设为 `subtle=0.25`、`balanced=0.50`、`strong=0.75`，有效值必须裁剪到当前风格的 `min..max`。
- 显式选择 12 风格后默认 `palette_mode=adaptive`，从当前布局的最终照片裁切提取主题色并适配该风格；此时 12 风格的显式选择覆盖 `portrait` 的灰橄榄绿默认值。
- 只有用户明确要求统一色系、全部同色或给出统一色值时，才切换到 `palette_mode=unified`。可采用用户色值，也可从整组照片的最终裁切共同提取代表色；不能仅因为选择了同一 `style_id` 就默认统一颜色。
- 所选风格锁定材质、纹理、光型、阴影、纵深和强度身份。若照片主题色与原注册表色相不同，保留这些非色彩身份，再用 `scripts/adapt_background_plate.py` 确定性适配色相；不能用强滤镜改照片来迁就背景。
- 信息联仍属于票根主体，不自动套背景材质；它优先从当前照片取色，并与背景保持清楚层级。
- 纹理、颗粒、窗影、光斑和矿物变化只能存在于外部背景平面，不能穿过照片、标题、日期、序列码和条形码。
- 背景复杂度保持 `low-medium`，对比度保持 `low`，纹理默认 `subtle`。主体必须是第一视觉层级。
- `strict` 模式下，先生成空背景底图，再通过确定性脚本合成票根；不得把带材质背景的模型成图直接当作最终照片区。
- 背景底图必须精确 `1170 × 1560`。禁止为适配尺寸而拉伸纹理；尺寸不符时重新生成或使用不破坏比例的画布归一化后再检查。

### 阴影规则

图集风格的阴影预设控制票根与背景的空间距离：`flat`、`subtle_float`、`premium_float`、`architectural`。无显式风格时继续使用已经通过验证的旧版双层阴影；显式风格时使用注册表推荐值或用户指定值。无论选择哪一档，都保留接触阴影，禁止变成发光、硬描边或第二张卡片。

### 推荐器规则

用户不记得风格 ID 时，根据题材、材质词和氛围词推荐。多方案选择以材质、光线、纹理、温度和纵深差异为目标；不得把“米色、浅米色、奶油米色、暖米色”当作四种不同方案。

## 已验证的不变量

- 一张画布只出现一张票根，四周保持负空间；不得同时出现横版和竖版两张卡片。
- `landscape` 的左右间距锁定为 `55px / 58px`，信息联在右侧；`portrait` 的票根锁定为 `560 × 1180px` 并水平居中，信息区在照片下方。
- 照片保持自然色和真实主体；配色只作用于画布、信息联和文字。
- 照片面板直接来自原始文件的等比例裁切；禁止把生成模型重构的照片区当最终素材，禁止非等比缩放和 JPEG 中间转码。
- 分隔处只能有一条方角虚线：`landscape` 为竖线，`portrait` 为横线。不得同时保留两种方向或第二条亮边。
- 标题、日期、编号、8 位码和条形码保持固定阅读顺序。
- 批量任务默认锁定同一 `layout` 和对应几何。横版无指定背景时逐图取主题色；竖版无指定背景时锁定同一灰橄榄绿织物身份。锁定显式风格 ID 时保持材质、纹理、光型、阴影、强度和纵深身份一致，并按显式风格规则逐图适配。

## 内容边界

- 手机状态栏、通知、播放器、按钮和进度条属于截图伪影，全部排除。
- 不伪造城市、品牌、拍摄日期、人物身份、商品、招牌或可扫描票码。
- 不改变人物五官、发型、眼镜、服装、姿势和手部动作。
- 不增加或删除动物、车辆、建筑、产品和重要道具。
