# 旅行票根视觉规范

## 画布与几何

| 项目 | 规格 |
| --- | --- |
| 画布 | `1170 × 1560`，严格 `3:4` |
| 票根主体坐标 | 名义 `x=55, y=501`；阴影不计入主体边界 |
| 票根主体尺寸 | `1057 × 507px`，比例约 `2.08:1` |
| 票根占画布 | 宽 `90.4%`，高 `32.5%` |
| 负空间 | 约 `67.5%` |
| 左侧照片 | `774 × 507px`，票根宽度 `73.2%`，目标比例约 `1.53:1` |
| 右侧信息联 | `283 × 507px`，票根宽度 `26.8%` |
| 外边距 | 左 `55px`、右 `58px`；这是参考图缩放后的锁定值，不强行改成数学等宽 |
| 光学居中 | 票根主体中心比画布几何中心上移约 `26px`；下方软阴影补足视觉重心 |

这些参数来自已确认的参考布局、确定性版式脚本和通过验收的成品。生成目标使用精确值；目视验收容差为：左边距 `51–59px`、右边距 `54–62px`、两侧差值 `0–7px`，票根主体顶部 `489–513px`、高度 `495–519px`。超过容差必须重做，不能用“约居中”放行。

票根外轮廓使用小圆角。照片与信息联之间在画布 `x≈829px` 只能出现一条竖向虚线：宽 `7px`，短矩形段高 `14px`、间隔 `12px`，第一段从票根顶部开始，所有线段必须是直角矩形，虚线顶部不得圆角、不得留出圆角式空隙。信息联最右侧垂直中点设置一个向内的半圆缺口。不要添加外边框。

阴影使用两层：近距离接触阴影约偏移 `(3, 5)`、模糊 `8px`、低不透明度；大范围环境阴影约偏移 `(2, 12)`、模糊 `26px`、更低不透明度。阴影应在照片和信息联整张票根周围连续，尤其加强下缘的落地感；上缘保持克制。禁止阴影断裂、只出现在信息联、变成描边、发光、脏色块或第二张卡片。

## 信息层级

阅读顺序固定为：照片 → 大写标题 → 日期 → 编号 → 8 位序列码 → 装饰条形码。

```text
OLD
TOWN

2026 - 08

NO.19427
E5R8K3M2
||||||||||||
```

- 使用超粗几何无衬线体，左对齐。
- 标题通常分成两行；优先在词间换行，单个长词按视觉平衡拆分，不机械按固定字符数切割。
- 日期和编号使用同一家族粗体，字号低于标题。
- 条形码只是装饰，不声称可以扫描或编码真实数据。

## 自适应配色

1. 从当前照片提取 2 至 3 个代表色；忽略极小面积高光、纯黑阴影、UI 和水印颜色。
2. 选择一个不与主体争抢注意力的支撑色作为画布色。默认将其调整为 HSL 饱和度 `6–20%`、明度 `58–62%`；已验收成品的稳定中心值为 `L=60%`。
3. 画布背景必须是边到边的单一纯色。禁止渐变、暗角、纸纹、噪点、光斑、投影色块或上下不同色。
4. 信息联使用照片中的深色或较鲜明次主色，与画布形成清楚层级，但不使用无来源的品牌色。优先保持同一色相家族或照片中真实出现的互补色。
5. 小号日期、编号和序列码与信息联的对比度至少达到 `4.5:1`；大标题至少 `3:1`。优先使用暖白 `#F4F0E5`，对比不足时加深信息联或改用深色文字。
6. 参考图默认只提供几何和视觉层级，不提供本张海报的背景颜色；只有用户明确指定色值时才覆盖自适应取色。
7. 保持照片自然，不叠加重滤镜、霓虹、复杂渐变或明显胶片特效。

常见映射：植物 → 灰绿与树皮棕；砖墙 → 陶土与砂岩；海景 → 青蓝；夕阳 → 焦橙；沙漠 → 沙米与旧红；精品店 → 香槟与灰粉。

## 已验证的不变量

- 一张画布只出现一个水平票根，四周保持大面积负空间。
- 票根左右间距锁定为参考图的 `55px / 58px`；信息联始终在右侧，缺口始终位于最右边垂直中点。
- 照片保持自然色和真实主体；配色只作用于画布、信息联和文字。
- 照片面板直接来自原始文件的等比例裁切；禁止把生成模型重构的照片区当最终素材，禁止非等比缩放和 JPEG 中间转码。
- 分隔处只能有一条方角虚线；归一化前先清除生成信息联左缘已有的虚线、亮边或阴影线。
- 标题、日期、编号、8 位码和条形码保持固定阅读顺序。
- 批量任务锁定几何，但允许每张照片拥有不同的支撑色与信息联色。

## 内容边界

- 手机状态栏、通知、播放器、按钮和进度条属于截图伪影，全部排除。
- 不伪造城市、品牌、拍摄日期、人物身份、商品、招牌或可扫描票码。
- 不改变人物五官、发型、眼镜、服装、姿势和手部动作。
- 不增加或删除动物、车辆、建筑、产品和重要道具。
