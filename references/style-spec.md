# 旅行票根视觉规范

## 画布与几何

| 项目 | 规格 |
| --- | --- |
| 画布 | `1170 × 1560`，严格 `3:4` |
| 票根主体坐标 | 名义 `x=55, y=501`；阴影不计入主体边界 |
| 票根主体尺寸 | `1057 × 507px`，比例约 `2.08:1` |
| 票根占画布 | 宽 `90.4%`，高 `32.5%` |
| 负空间 | 约 `67.5%` |
| 左侧照片 | `774 × 507px`，票根宽度 `73.2%`，目标比例约 `1.53:1` |
| 右侧信息联 | `283 × 507px`，票根宽度 `26.8%` |
| 外边距 | 左 `55px`、右 `58px`；这是参考图缩放后的锁定值，不强行改成数学等宽 |
| 光学居中 | 票根主体中心比画布几何中心上移约 `26px`；下方软阴影补足视觉重心 |

这些参数来自已确认的参考布局、确定性版式脚本和通过验收的成品。生成目标使用精确值；目视验收容差为：左边距 `51–59px`、右边距 `54–62px`、两侧差值 `0–7px`，票根主体顶部 `489–513px`、高度 `495–519px`。超过容差必须重做，不能用“约居中”放行。

票根外轮廓使用小圆角。照片与信息联之间在画布 `x≈829px` 只能出现一条竖向虚线：宽 `7px`，短矩形段高 `14px`、间隔 `12px`，第一段从票根顶部开始，所有线段必须是直角矩形，虚线顶部不得圆角、不得留出圆角式空隙。信息联最右侧垂直中点设置一个向内的半圆缺口。不要添加外边框。

阴影使用两层：近距离接触阴影约偏移 `(3, 5)`、模糊 `8px`、低不透明度；大范围环境阴影约偏移 `(2, 12)`、模糊 `26px`、更低不透明度。阴影颜色由本张画布色向近黑调和，不固定使用暖黑。阴影应在照片和信息联整张票根周围连续，尤其加强下缘的落地感；上缘保持克制。禁止阴影断裂、只出现在信息联、变成描边、发光、脏色块或第二张卡片。

## 信息层级

阅读顺序固定为：照片 → 大写标题 → 日期 → 编号 → 8 位序列码 → 装饰条形码。

```text
OLD
TOWN

2026 - 08

NO.19427
E5R8K3M2
||||||||||||
```

- 信息联本地坐标以票根左上角为原点。文字左边缘固定为 `x=822px`，即信息联内边距 `48px`。
- 标题顶部 `y=48px`，最大宽度 `211px`，字号在 `32–64px` 内取能完整容纳文字的最大值，使用超粗几何无衬线体。
- 标题使用一到两行。优先在词间换行；单个长词只有在最小 `32px` 仍无法容纳时才按视觉平衡拆分。自动英文场景词使用大写；用户指定文本逐字保留。中文标题使用重黑 CJK 字体，不做 uppercase 转换。
- 日期顶部 `y=238px`，最大宽度 `179px`，避开右侧中点缺口；编号顶部 `y=326px`，序列码顶部 `y=367px`。
- 条形码顶部 `y=420px`、高度 `43px`、最大宽度 `192px`。它只由序列码确定性生成，不声称可以扫描。
- 日期约 `31px`，编号和序列码约 `27px`；必要时只向下缩至 `25px / 23px`，不得溢出或挤压安全区。
- 所有信息左对齐。使用本地粗体字体确定性排版；生成模型的文字只作为例外预览，不作为逐字准确的最终层。

## 自适应配色

完整执行 [palette-system.md](palette-system.md)。不可跳过的摘要如下：

1. 只在最终 `774 × 507` 裁切上取色，先排除白边、黑边、高光、死影、UI，以及不属于环境的皮肤、头发和服装。
2. 每张照片生成 `quiet-light / editorial-mid / cinematic-deep` 三套有来源记录的方案，再目视选择；任何预设都不能跨图片直接复用。
3. 默认背景软区间为 OKLCH `L=0.64–0.78, C=0.02–0.08`。叙事明确时允许照片派生的深红、深蓝、亮黄或陶土色，不能再把 HSL `S=6–20%、L=58–62%` 当作唯一高级答案。
4. 背景与信息联的 `Delta OK` 理想为 `0.14–0.38`，低于 `0.10` 禁止交付。文字对比生成目标 `5:1`，硬门槛 `4.5:1`。
5. 画布必须为边到边单一纯色。触感来自精确裁切、排版和双层阴影，不靠背景纸纹、噪点、暗角或滤镜制造。
6. 参考图只控制几何和视觉层级，不提供本张海报的颜色；只有用户明确指定色值时才覆盖自适应背景。
7. 保持照片自然，不叠加重滤镜、霓虹、复杂渐变或明显胶片特效。

## 已验证的不变量

- 一张画布只出现一个水平票根，四周保持大面积负空间。
- 票根左右间距锁定为参考图的 `55px / 58px`；信息联始终在右侧，缺口始终位于最右边垂直中点。
- 照片保持自然色和真实主体；配色只作用于画布、信息联和文字。
- 照片面板直接来自原始文件的可见像素：先修正 EXIF，透明区域安全铺底，默认清除明确的边缘白/黑装裱条，再等比例裁切。禁止把生成模型重构的照片区当最终素材，禁止非等比缩放和 JPEG 中间转码；用户确认边框属于作品内容时使用 `--keep-neutral-borders` 全程保留。
- 标准任务由 `render_ticket_poster.py` 确定性完成背景、原图裁切、信息联、文字、条码、虚线、缺口和阴影；图片生成只处理确定性裁切无法解决的非语义环境扩展等例外。
- 分隔处只能有一条方角虚线；归一化前先清除生成信息联左缘已有的虚线、亮边或阴影线。
- 标题、日期、编号、8 位码和条形码保持固定阅读顺序。
- 批量任务锁定几何，但允许每张照片拥有不同的支撑色与信息联色。

## 内容边界

- 手机状态栏、通知、播放器、按钮和进度条属于截图伪影，全部排除。
- 不伪造城市、品牌、拍摄日期、人物身份、商品、招牌或可扫描票码。
- 不改变人物五官、发型、眼镜、服装、姿势和手部动作。
- 不增加或删除动物、车辆、建筑、产品和重要道具。
- 票根区域禁止新增飞机、地图线、指南针、邮戳、护照章、QR 码、价格、货币、假标签、额外微缩字、孔洞、撕边、胶片框或第二张票根。
- “不新增 Logo 或文字”只约束票根和画布区域；原照片中已经存在的招牌、产品或建筑细节必须原样保留。
